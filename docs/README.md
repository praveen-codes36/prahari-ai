# docs/

## What goes here

- `PS.md` or `PS.pdf` — the finalized problem statement (SIH format)
- `architecture-diagram.png` — system architecture diagram
- `PRAHARI-PPT.pptx` — the prescribed-format presentation
- `demo-script.md` — the rehearsed pitch/demo walkthrough
- `screenshots/` — dashboard screenshots for the PPT and README
- Any cited sources (MoRTH reports, CAG/NITI Aayog data) used to justify
  the problem statement

## Suggested PPT structure

1. Title slide — PRAHARI, team name, theme
2. Problem statement + real-world evidence (cite MoRTH/data.gov.in stats)
3. Proposed solution overview (the 3-module diagram)
4. System architecture
5. Tech stack
6. Live demo screenshots (defect detection → risk heatmap → safe routing)
7. Impact & feasibility
8. Future scope / scalability
